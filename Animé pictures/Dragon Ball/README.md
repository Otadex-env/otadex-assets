# Dragon Ball — images des personnages

Dépose ici les images brutes de chaque personnage, dans son propre dossier.
N'importe quel nom de fichier / format (jpg, png, webp...) convient : le
renommage et la conversion en JPEG se font automatiquement ensuite.

Convention finale (générée par `scripts/push_images.js`, pas à faire à la main) :
`db_[4 premières lettres du slug][numéro].jpeg`

Minimum recommandé : 4 images par personnage, idéal 8-13.
